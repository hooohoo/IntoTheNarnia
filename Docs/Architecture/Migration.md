## 보존 및 완료 조건

게임 동작(Title 시작, 로딩, Lucy 이동, 카메라, 대화, 설정, 문, 포털), Inspector/UnityEvent 연결, Animator State 값, Resources 상대 키, 태그/Area 이름, 씬·프리팹·에셋 GUID를 보존합니다. 표준 JSON 배열을 추가 지원하되 기존 대화 데이터도 읽습니다. 35개 CP949 스크립트는 내용을 보존하며 UTF-8로 변환합니다.

자체 코드의 매 프레임 Unity 콜백과 코루틴을 정리하고 취소·해제 경로를 구현합니다. 초기화 순환, 반복 씬 진입, 재활성화, 대화 중단, 중복 로딩 요청을 검증합니다. 프로젝트를 로드할 때 새 Missing Script/직렬화 참조 오류가 없어야 합니다. 새 폴더 경로를 Build Settings와 문서에 반영합니다.

빈 방 씬의 신규 레벨 제작, 엔진·렌더러 업그레이드, 외부 아트 패키지 재작성은 구조 개편의 완료 조건이 아닙니다. 기존 예제는 Samples로 분리하되 삭제하지 않습니다.
