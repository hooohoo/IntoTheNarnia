# Professor House · 완성 분위기 시안 01

`index.html`에서 완성 분위기 이미지 7장과 기존 구조 모형을 함께 확인합니다. `Images/`의 PNG는 원본 그대로 보존했습니다.

- 01: 전체 저택의 층별 마감 개요
- 02: 높은 아치창과 비대칭 계단이 있는 중앙 홀
- 03: 2층 서쪽 교수 서재
- 04: 2층 동북쪽 끝 여자아이 침실
- 05: 서쪽 정원 창문 사고가 시작되는 1층 유물 전시실
- 06: 아치창 뒤 외부 후정
- 07: 다락 끝 옷장방과 루시

확인한 연결 모형 01과 확정 도면 03을 바탕으로 재질·가구·조명을 제안한 컨셉입니다. 정확한 치수, 계단 단수, 출입구, 충돌 및 이동 경로의 기준은 도면·연결 모형입니다. 생성 이미지의 세부 형태는 제작 과정에서 그 기준에 맞춰 조정합니다. 전체 절개도는 층별 관계와 마감 개요이며 모든 방의 가구를 완성한 배치도가 아닙니다.
