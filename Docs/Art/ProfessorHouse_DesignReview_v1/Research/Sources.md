# 조사 근거와 반영 범위

2026-10-22 · 2005년 영화 기준 · 구조 관련 공개 이미지 24장 선별(영화 프레임·공개 스틸 20장, 제작 스토리보드 4장).

## 근거를 합치는 순서

사용자가 승인한 v2 시안의 핵심 홀·옷장 방과 둥근 다크 우드 스타일을 유지한다. 영화에서 확인하는 요소, 사용자가 직접 만든 원본 씬의 좋은 동선, 통합을 위한 새 연결부를 하나의 제안으로 조합한다. 시안 자체를 폐기하거나 영화의 핵심 공간을 다른 컨셉으로 대체하지 않는다.

- F: 영화에서 직접 볼 수 있는 부분 요소. 방 전체의 위치·치수·인접 관계가 확정됐다는 뜻은 아니다.
- S: 승인된 v2 시안의 형태·재질·분위기.
- U: 사용자가 만든 원본 씬에서 계승한 분기 계단·여러 높이·긴 회랑·방 사이 탐험 동선.
- P: 전체를 연결하기 위해 제안한 배치, 중정, 관리 공간과 보조 계단.

## 제작 자료

- [Roger Ford 제작 디자인 인터뷰](https://www.narniaweb.com/2005/10/lecran-fantastique-interviews-roger-ford/): 여러 영국 저택을 참고해 별도 세트를 구성하고 시대별 변화도 고려했다는 설명. 특정 실제 저택의 내부 평면을 영화 전체 구조로 단정하지 않는 근거다.
- [John DeCuir Production Design Studies Center / Asbury University 아카이브](https://asburyproductiondesignstudiescenter.com/designs-2130/2025/4/16/the-chronicles-of-narnina-the-lion-the-witch-and-the-wardrobe): 제작 스토리보드를 참고했다. 초기 스토리보드는 완성 영화와 다를 수 있으므로 스틸컷보다 우선하지 않는다.
- [영화 로케이션 설명](https://www.movie-locations.com/movies/c/Chronicles-Of-Narnia-Lion-Witch-Wardrobe.php), [2006년 외부 촬영지 방문 기록](https://www.narniaweb.com/2006/02/professors-house-location-pictures/): 외부의 참고 건물과 실제 촬영 장소, 영화 속 저택을 구분하는 보조 자료. Kentwell Hall의 실제 평면을 영화의 내부 설계도로 사용하지 않았다.
- [Disney/Walden 교육 자료](https://www.awesomestories.com/media/user/ab6a9940bc.pdf): 제작 디자인의 배경 설명을 확인했다. 집 전체를 확정할 수 있는 도면으로 사용하지 않았다.

## 기존 프로젝트 기준

- 비교 대상: 원본 `Professor_House.unity`, Git `7e5086271612f37c0cd5ec18deca77b617f37bfd`.
- 별도 임시 Unity 프로젝트에서 원본을 열어 6,378개 Renderer의 위치를 확인했다. 비교 캡처 U01/U02는 구조를 보기 위한 간소화 조명이며 원본의 최종 색감이나 기존 베이크를 재현한 화면은 아니다.
- 원본에서 중앙 짧은 계단과 양쪽 분기, 여러 중간 층, 옆으로 길게 뻗어 꺾이는 회랑, Siblings/ Wardrobe 목적지의 분리를 확인했다.
- 모든 원본 벽의 좌표를 그대로 유지하는 안은 아니다. 기존 구조의 장점을 계승하면서 시안의 핵심 공간을 통합한 재설계 제안이다.

## 조사 한계와 판단

공개 검색·이미지 검색, 초반/중반/후반 스틸, 제작 인터뷰와 아카이브를 조사하고 이미지 43장을 수집한 뒤 건축 검토에 관련 있는 24장을 선별했다. 스크린캡 아카이브의 페이지 목록도 확인했으나 일부 이미지 CDN은 접근에 실패했다. 인터넷의 모든 이미지 또는 비공개 제작 도면을 확보했다는 의미는 아니다. 전체 저택을 확정할 수 있는 인증된 완성 세트 평면도는 이번 조사에서 확보하지 못했다.

모든 치수, 층고, 방의 동서남북 위치와 전체 인접 관계는 게임용 제안이다. 특히 외관의 뒷면, 중정, 주방·식당·관리인 공간, 남자아이 방의 내부 배치와 보조 계단은 P에 해당한다. 영화의 컷 전환은 바로 옆 방이라는 증거로 사용하지 않는다. 1988 BBC판, 다른 나니아 영화의 성, 새로운 영상화 작품, 팬 평면도는 2005년 저택의 확정 근거에서 제외했다.

참고 이미지는 검토 문서에만 포함한다. 게임의 텍스처·런타임 리소스로 등록하지 않는다.
