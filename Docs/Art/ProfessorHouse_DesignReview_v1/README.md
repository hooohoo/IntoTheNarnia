> 현재 공간 배치·높이·문 연결 기준은 [확정 도면 v1](../ProfessorHouse_ApprovedLayout_v1/README.md)이다. 이 묶음의 보드·레퍼런스는 형태와 분위기 참고로 유지한다. 아래 2층 +3.60m·다락 +7.20m와 초기 방 배치는 당시 제안 이력이며 후속 제작 기준으로 사용하지 않는다.

## 설계 기준

| 구역 | 유지한 핵심 | 새로 제안한 연결 |
|---|---|---|
| A 외관·진입 | 영화의 벽돌, 돌 창틀, 박공, 깊은 입구 | 전실, 후면과 동쪽 날개, 중정 |
| B 계단 홀 | 시안의 아치문·흉상·의자·다크 우드, 원본의 공통 계단과 양쪽 분기 | 상층 회랑의 연속성과 수치 |
| C/D 생활·서재 | 창가 벤치, 벽난로, 책과 수집품 | 응접실→서재→서고, 현관→식당 |
| E 가족 공간 | 침실 마감, 꺾이는 복도와 여러 문 | 방의 위치·가구 배치, 욕실·린넨실 |
| G 옷장 방 | 시안, 왼쪽 창 2개, 빈 마루와 지붕 보, 새틴 옷장 | 외벽 배치와 보조 계단 접근 |
| F 회랑·관리 | 기존 씬의 길고 꺾이는 탐험 동선 | 중정 둘레, 주방·준비실·관리 공간 |

## 제안 수치와 동선

전체 외곽은 50 × 34m, 동쪽 중정은 14 × 16m다. 기본 바닥 높이는 1층 +0.00, 2층 +3.60, 다락 +7.20m다. 영화 실측이 아닌 게임용 제안치다.

주 계단은 8단으로 +1.44m 공통 계단참에 오른다. 왼쪽은 12단으로 +3.60m, 오른쪽은 7단으로 +2.70m 계단참에 오른 뒤 꺾어 5단으로 +3.60m에 닿는다. 단 높이 0.18m 기준이다. 보조 계단은 층마다 10+10단을 같은 위치에 쌓는다. 최종 구현 시 충돌·머리 공간·카메라와 캐릭터 축척을 검증해야 한다.

기본 탐험은 현관→계단 홀→상층 갤러리→가족 복도→보조 계단→다락의 꺾이는 복도→옷장 방이다. 옆으로는 응접실·서재·서고와 중정 회랑을 연결한다. 옷장 방은 입구를 남쪽 끝, 옷장을 북쪽 끝에 두고 서쪽 외벽 창을 유지한다. 방위는 도면 정리를 위한 임의의 기준이며 영화의 실제 방향을 확정한 것이 아니다.

이미지의 작은 절개도는 공간감과 조형을 보여주는 개념 시안이다. 전체 배치와 문·계단의 위치는 `Plans/*.svg`와 [공간 계약](Plans/spatial-contract.json)을 기준으로 검토한다. 생성 이미지의 세부 가구·난간 개수나 화면상의 비율을 실측치로 취급하지 않는다.

## 상태

시안 7장, 층별 도면 3장(PNG/SVG), 선별 공개 레퍼런스 24장, 원본 비교 캡처 2장과 승인 시안 1장을 묶었다. 내장 `image_gen`을 사용했으며 CLI/API를 사용하지 않았다. Lucy는 기존 시안의 크기 참고로만 등장하고 캐릭터 모델은 수정하지 않았다. Unity 프로젝트의 씬·메시·조명·게임 코드는 이 검토안으로 변경하지 않았다. 기존의 미커밋 구현은 별개 상태로 남아 있다. 커밋·병합·push는 하지 않았다.

전체 검토 후 B의 핵심 분위기와 분기 방식, F의 긴 탐험 동선, G의 접근 거리를 먼저 확정한다. 그다음 방/계단/벽면 단위의 통합 메시를 만들고, 문과 옷장 문은 독립 오브젝트로 유지한다.
