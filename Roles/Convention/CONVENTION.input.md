# 입력

InputManager가 기존 Input Manager와 조이스틱 값을 읽고 입력 전략이 이동·카메라 허용 여부를 결정합니다. 상태는 자신의 전략을 한 번 생성하여 Enter/Exit에서 연결/해제합니다. 게임 객체는 입력 장치를 직접 폴링하지 않고 InputManager의 프레임 입력을 소비합니다.

조이스틱 종료·비활성화·씬 이동 때 값과 드래그 상태를 초기화합니다. UI 위에서 시작한 포인터 입력은 카메라 회전으로 전파하지 않습니다. 현재 카메라 입력은 기존 마우스 축을 사용하며 별도 멀티터치 제스처는 구현하지 않습니다. 설정/로딩/대화 상태에서 이동·카메라 입력을 차단합니다. 중첩 UI가 닫힐 때 이전 게임 상태를 복구합니다.
