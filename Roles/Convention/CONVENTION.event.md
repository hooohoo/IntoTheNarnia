# 이벤트

타입으로 구분한 이벤트와 명시적인 리스너 인터페이스를 사용합니다. 등록한 소유자가 해제하며 중복 등록을 방지합니다. 순회 중 등록·해제는 현재 알림의 스냅샷을 바꾸지 않는 정책을 사용합니다. 역순 순회만으로 모든 변경이 안전하다고 가정하지 않습니다. 해제된 수신자는 호출 전에 확인합니다.

이벤트 데이터는 발행 후 변경하지 않습니다. 재진입/비동기/큐 처리에서 공유 payload를 재사용하지 않습니다. 하나의 수신자 오류가 다른 수신자를 영구적으로 차단하지 않도록 경계에서 보고합니다. 단순 컴포넌트 입력은 uGUI/물리 콜백으로 받고 도메인 변화만 이벤트로 발행합니다.
