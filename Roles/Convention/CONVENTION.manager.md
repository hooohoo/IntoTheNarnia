# 매니저

IManager의 Init/Release를 구현하고 FacadeManager에 명시적으로 등록합니다. Singleton<T> 접근은 부트스트랩/호환 어댑터에 한정합니다. 매니저 간 필드에는 [Singleton(typeof(T))]를 붙입니다. 초기화 전에 모든 의존성을 주입하고 위상 순서로 Init합니다. 누락·순환·중복 등록을 허용하지 않습니다. 종료와 초기화 실패 시 역순으로 Release합니다.

씬 객체 참조와 전역 서비스를 구분합니다. 씬 해제 시 Object/Camera/UI의 씬 참조를 비웁니다. 부분 클래스는 책임이 실제로 나뉠 때만 도입합니다. 빈 partial hook을 형식적으로 만들지 않습니다. 프레임 루프, 이벤트, 취소 토큰은 등록한 소유자가 해제합니다.
