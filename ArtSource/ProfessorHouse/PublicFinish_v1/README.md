# Public Finish v1

확정 도면의 1층 C1 응접실·A 현관·C2 식당·D2 공용 도서실 마감 원본이다. 미터 단위 Blender Z-up, Unity (X,Z,Y) 변환을 사용한다.

`Tools/Art/build_professor_house_public_finish.py`와 공통 `professor_house_finish_kit.py`로 재생성한다. 승인 layout/model-spec의 문·창·층고·서사 동선은 유지한다. 새 원본은 방 마감·가구·커튼 묶음으로 합쳐 저장하며 기존 홀 그림 아틀라스를 포함한다.
